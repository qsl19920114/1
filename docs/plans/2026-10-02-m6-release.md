# M6 稳定与 macOS 发布

G4/G5 通过后执行；主平台 macOS arm64。Qt 随包部署；固定 Hypit、Node、FFmpeg/ffprobe 及所选渲染浏览器为外部依赖，不 vendor 上游。没有正式 Apple 身份，产物为 ad hoc 本地课程交付包，记录此边界。

- [ ] T029：配置输入有界、日志轮转、界面日志有界；工程和素材继续使用已验证路径策略。增加仅当前终态导出冻结目录的清理入口，活动或未知任务禁止删除；真实关闭仅清理自有 Studio。
- [ ] T030：应用资源从 executable/bundle 相对路径定位，删除绝对模板编译常量；生成 `.app` 和相对布局配置；每个 QProcess 使用应用级工具解析结果（进程 PATH），不改系统配置。打包脚本部署 Qt/WebEngine、检查全部实际 Mach-O 链接/RPATH、helper 资源/签名权限，收集实际第三方许可材料、生成 ZIP 与 SHA256。
- [ ] T031：新增无截图 `--verify-startup --create-project <目录>`，使用 bundle 模板新建真实工程并验证 Snapshot、已编译预览、图片加载和退出清理；移动至中文空格路径，非仓库 CWD、初始最小 PATH；默认同级 Hypit 与显式配置两种布局；缺依赖返回清晰非零结果。
- [ ] T032：最终使用指南、开发/复用边界、架构更新、测试报告、版本与外部安装说明。保存真实样例 MP4 和完整操作演示视频；后者由 Qt 自己窗口的连续录制记录真实创建/导入/编辑/撤销/提案确认/导出/重开，不以合成画面代替实际运行，也不作为截图门禁。

实现代理负责基础设施/缓存清理服务与测试；主代理负责 main/UI、构建部署脚本、真实搬移运行及演示材料。规格与质量审查通过后才更新 G6、提交推送。Windows、公证、另一台无 Qt 主机、真实模型均未验证时明确写出，不宣称跨平台发布。

参考 `docs/M6_RELEASE_RESEARCH.md` 中已核对的固定源码与官方部署说明。任何发布命令的成功结论必须来自本轮实际输出。
