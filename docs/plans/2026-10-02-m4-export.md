沿用已批准 PROJECT_PLAN，继续现有 qt-video-workbench 分支。使用 subagent-driven-development、TDD、规格及质量复审；不截图验收。

**目标：** Qt 内完成本地计划、持久化构建提交、状态观察、指定任务取消、精确 Output 获取、MP4 参数及全片解码验证。

**设计：** ExportController 一次管理一个导出。导出前把工程源码、可信包和素材复制到工程内独立构建目录，核对 Snapshot 白名单预像，记录 revision/指纹，构建固定输入；用户后续编辑不会改变这次导出。任务记录原子保存，关闭仅停止观察，再打开恢复观察。CLI 参数使用固定源码契约；不得把 CLI exit0 当成成片成功。

## 固定CLI依据

Hypit0.2.10 packages/cli/src/arguments.ts:110–130：build支持--workspace、--runtime、--json，不带--follow只提交。
main.ts:400–501：Build由Worker拥有；machine format hypit.cli-build@1。
main.ts:623–655：plan含ok、providerRequestCount、preflight。
commands/execution.ts:240–313：status format hypit.cli-status@1，build.work与build.result分开；failed/attention可能exit1。
commands/execution.ts:365–391：cancel format hypit.cli-cancel@1 requested不代表终态。
commands/results.ts:187–198：get <id> --output final.video --to <path> --workspace <frozen> --json返回build/output/path。
view.ts:60–96：result.state==complete才可取；只认精确ID。
