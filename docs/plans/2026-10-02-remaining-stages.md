# M5 / M6 后续执行范围

沿用用户批准的 PROJECT_PLAN；M4门禁完成后才实施。本文件把实际剩余任务具体化，继续逐阶段验证、提交与推送。

## M5：受约束编辑提案

- T025：单操作EditProposal（format、revision、sourceFingerprint、entityId、fieldId、value、来源）。必须匹配当前可写字段；图片只来自已导入素材；禁止Source、Shell、任意路径和多操作。
- T026：原生提案卡显示当前值、拟修改值及来源；用户点确认时再次核对版本/指纹，通过同一个EditorController写入并记录历史。重开、外部改动和过期提案自动失效。
- T027：可替换提案Provider；本地演示Provider显式标“模拟”，支持标题/颜色/已导入图片三种受限请求；可导入符合相同Schema的外部提案JSON，并明确来源未核验。不要求账号，不把模拟宣称为真实模型。
- T028：恶意/畸形/过期/越权/不可写/并行提案测试；真实Studio确认一项有效提案，撤销可恢复。实际模型为可选能力，未配置时保留未验收标识。

## M6：主平台稳定与发布

- T029：复核工程/素材/任务恢复路径、日志与输入大小、关闭清理；只清理应用自己的终态缓存，禁止删除工程输入或活动Build。
- T030：macOS .app、Qt/WebEngine运行库、原创模板、配置示例、第三方说明。运行时从bundle资源定位模板；Hypit/Node/FFmpeg明确为外部依赖，通过配置与本进程PATH解析，源码仓库不vendor。
- T031：应用移到含中文空格目录并从非仓库工作目录启动；无截图verification模式读取真实工程和Studio编译预览，验证退出时自有进程清理。Qt链接检查与发布包校验和保留证据。
- T032：使用指南、演示操作步骤、架构/原创复用说明、测试报告、本地示例成片、许可证与运行包。主平台为macOS arm64；Windows与可选真实模型不做未验证的成功宣称。

每阶段完成后更新tasks.json、STATUS和README，审查及验证通过才提交。最终交付包含可运行应用和源代码、真实成片、复现命令及清晰依赖边界。
