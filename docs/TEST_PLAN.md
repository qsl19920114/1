# 测试与门禁

按 tasks.json 的实际任务编号推进。用户在 2026-09-24 明确要求不再专门截图验收；后续采用可复现的构建、测试、真实 HTTP/CLI 和媒体解码结果。原有截图证据保留为历史。

## M2

- ProjectStore：新建/重开、中文空格目录、迁移、损坏格式、路径逃逸、原子保存失败和复制失败回滚。
- AssetService：真实 PNG/JPEG 解码、按内容识别而非扩展名、去重、尺寸/大小限制、源文件不变、既有资源不覆盖、登记失败恢复。
- DocumentController：新建/保存/关闭/重开、打开失败保留当前文档、素材登记。
- 原创模板：文本、主题色、图像 artifact 进入视觉元素；不合法颜色与帧数拒绝；真实 Hypit check/plan。
- 独立工程集成：使用生产 Controller/Service 创建和导入；移动目录后重开；真实 Studio GET 返回 1280×720、240帧、5个声明的可写字段以及绑定图片。退出结束自有进程。

## M3

- StudioWriter：本机 HTTP、严格状态码/revision、超时、响应大小、取消、并行拒绝与重入。
- EditorController：写前/写后确认、409 与 422 的不同恢复、未知结果不重试、异步历史、关闭隔离、数值字面量转换、Source 依赖集合变化。
- SourceEditGuard：真实白名单、预像、外部写入与符号链接替换保护；回读网络失败不自动恢复文件。
- 原生控件：五类控件、只读字段、真实提交值类型、数值显示精度不导致无意写入。
- `editor_e2e_test`：真实标题/颜色/图片、编译预览与图片字节、撤销重做、422 服务端回滚、Source 编译失败恢复、外部冲突、关闭重开。测试直接使用生产控制器，不截图。

## M4

- JsonProcess：有界stdout/stderr、严格JSON、绝对期限、取消、退出后重新start的回调隔离。
- ExportWorkspace：快照预像与输入hash冻结、中文路径、symlink和dataRoot逃逸、任务原子保存、恢复时输入篡改拒绝。
- MediaValidation：H.264/MP4、尺寸/帧率/时长、工具缺失、ffmpeg全片解码；未通过不发validated。
- ExportController：严格本地计划、真实诊断、精确ID/Output、Work与Result、取消终态、保存记录失败、未知提交恢复不重提、公开信号重入和取消隔离。
- `export_e2e_test`：生产Controller完成原创工程/图片/标题/颜色→真实成片；停止重开恢复同ID，原工程后续改动不污染冻结；实际取消及包语法错误的计划失败不交付。全过程不截图。

## M5

严格提案Schema、有界JSON与文本、来源由入口赋值、类型/可写字段/版本校验、工程素材白名单；模拟Provider仅三种受限指令。控制器测试覆盖确认前无写入、单次确认、忙时和过期拒绝、关闭重开失效、公开信号重入及跨工程绑定。真实`proposal_e2e_test`核对确认前实际源码不变，真实标题/图片写入与撤销，人工编辑使提案失效。真实模型未配置不计入通过。

## 后续硬门禁

M3 必须区分409冲突与422回滚，写入成功后才能推进撤销历史；重开工程一致。M4 必须区分 HTTP 接受、CLI 退出、Build完成、Output获取与成片可解码；用 ffprobe 和全片解码验证真正的 MP4。M6 验证发布包脱离开发机路径。

离线单测不替代真实集成。环境缺依赖或测试失败时不得更新门禁为 PASS。
