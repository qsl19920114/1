FRAMELAB / QT × AI × HYPIT

同一舞台，不同人物

在 Qt 中选择人物素材，由内嵌 Agent 生成受限方案，审阅确认后写回 Hypit，更新预览并导出。

本次实现的是人物图片素材替换：保留文案、版式与入场动画。没有对原视频人物进行换脸或动作重生成；模型接收登记信息，没有接收人物像素。三张人物素材复用 Hypit 官方归档，来源见下方清单。
